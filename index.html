          # features
          
Everything you reach for, one keypress away.

          

            Four tabs. Live stats. Deep inspection. tinyd treats Docker the way
            top treats processes — fast, focused, fluent.

          # install
          
Three lines and you're in.

          
Requires Go 1.19+ and a running Docker daemon (local or remote).

        


        

          

            
● clone & build

            
$ git clone https://github.com/jalonsogo/tinyd.git
$ cd tinyd
$ go build -o tinyd
$ ./tinyd

            
          


          

            
● remote docker

            
$ export DOCKER_HOST=tcp://host:2376
$ ./tinyd

            
          


          

            
● docker desktop

            
# autodetected on macOS / Windows
$ ./tinyd

            # who
            
Made by a designer. Mostly written by Claude.

            

              tinyd is an experiment in what happens when a designer hands the keys
              to an AI pair-programmer and asks for the smallest possible Docker
              Desktop. The result: a little terminal app that boots in milliseconds
              and stays out of your way.
